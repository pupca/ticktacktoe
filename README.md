# Tic·Tac·Toe

A small web game: two players, one screen, three in a row wins. Plain HTML, CSS and JavaScript, no build step,
no backend. Published with GitHub Pages: https://pupca.github.io/ticktacktoe/

The specification (user stories, design) lives in Polarion, project *Tic-Tac-Toe* (GAME).

Tests: `node --test tests/score.test.js` (Node 18 or newer, no install needed).
